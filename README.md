# Little-Lemon
Welcome to Little Lemon, a family owned mediterranean restaurant.

## Description
Little Lemon has faced difficulties with the reserve-a-table feature on its website. The feature doesn’t exist in the navigation bar and there is no specific button on its homepage to highlight this option. The Little Lemon Restaurant has fixed the issue on the website and the feature is ready to use.

## Features
Interactive Navigation:  Uses react router to navigate throughout the page.  The reserve-a-table option has been added to the navigation bar.
Responsive Hero Section:  A button has been added to the Hero section to highlight the reserve-a-table option.
Feature placeholders:  A "Coming soon" message has been placed for the parts of the website that are in the works.
Table Reservations:  A table reservation system has been put in place to manage reservations.

## Installation
Follow these steps to run application on your machine:
1. **Clone the repository**
git clone https://github.com
2. **Navigate to the directory**
cd Little-Lemon
3.  **Install dependencies**
npm install
4.  **Launch the local development server**
npm run start
Open [http://localhost:3000](http://localhost:3000) to view the website in your browser.

## Usage
To use this website, click on the options in the navigation bar.  There are five options to choose from:  Home, About, Menu, Reservations, Order Oline and Login.  Home will take you to the main page of the website where you can click on the reserve-a-table button to make reservations, take a look at the weekly specials, and read the customer's testimonials.  Once you are at the bottom of the page, you can click on "Home" in the footer to take you back to the top, or click on the other options listed.  The About link in the navigation will take you to the Little Lemon bio.  The Menu, Order Online and Login links will take you to a "Coming soon" message.  The Reservations link will direct you to reserve a table at Little Lemon.  Enter the date, time, number of guests and occasion and click the "Make your reservation" button.  A table with the bookings will be listed below as well.  Once you click the "Make your reservation" button, you wil be directed to a confirmation page.  Click the "Return to Home" button to be re-directed back to the Home page.  The footer will provide you with the social media of the website.
